O que é Front-end?

O desenvolvimento Front-end está relacionado à parte de uma aplicação que o usuário visualiza e utiliza diariamente.

Para desenvolver uma aplicação Web é importante compreender estrutura, apresentação e comportamento.

HTML não é responsável por criar o design da página. Sua principal função é estruturar o conteúdo.

O desenvolvimento Front-end utiliza diferentes tecnologias que trabalham em conjunto.

As três pricnipais tecnologias

  1. HTML - estrutura do contéudo.
  2. CSS - apresentação visual.
  3. JS - comportamento e interatividade.

HTML define a estrutura, CSS trabalha a apresentação e JavaScript permite adicionar comportamentos.

HTML - Estrutura da Web

O que é HTML?

HTML é uma linguagem de marcação utilizada para estruturar documentos Web.

Um documento HTML é composto por elementos. Por exemplo, o elemento p representa um parágafo.

Já o elemento a pode ser utilizado para criar um link.

Elementos HTML

Alguns elementos utilizados para estruturar uma página são:

  • h1 - título principal.
  • p - parágrafo.
  • a - link.
  • img - imagem.
  • ul - lista não ordenada.

Atributos HTML

Os atributos fornecem informações adicionais sobre os elementos HTML.

href
Define a origem de um link.
src
Define a origem de um recurso.
alt
Fornece uma descrição alternativa para a imagem.
title
Fornece uma informação complementar.
lang
Indica o idioma prioncipal do documento.

HTML Semântico

HTML semântico significa utilizar elementos que representam o significado do conteúdo.

Em vez de utilizar apenas div para toda a página, podemos utilizar elementos específicos para representar cada parte.

header
Representa o cabeçalho.
nav
Representa uma área de navegação.
main
Representa o conteúdo principal.
section
Representa uma seção do conteúdo.
article
Representa conteúdo independente.
aside
Representa conteúdo complementar.
footer
Representa o rodapé.

A tag div continua sendo útil para agrupamentos genéricos.

Este conteúdo destá dentro de uma div porque não possui uma função semântica específica.

Semântica Textual Inline

O HTML também possui elementos utilizados para representar o significado de pequenos trechos de tesxto.

Importância e enfâse

A tag strong indica grande importância.

A tag em pode indicar ênfase em determinada informação.

A tag mark pode destacar uma informação importante.

A tag small pode apresentar uma observação. Esta é uma informação complementar.

Código

Pequenos trechos de código podem ser representados utilizando code.

Por exemplo: <h1>Olá Mundo!</h1>

Exemplo completo

<h1>Olá Mundo!</h1>

Minha primeira página HTML.
</p>
<a>
href="https://www.w3.org/"
</a>

Teclado

Para salvar o arquivo utilize: Ctrl + S

Para copiar utilize: Ctrl + C

Para colar utilize: Ctrl + V

Saída do programa

Ao executar determinado programa, o sistema pode apresentar a seguinte mensagem:

Arquivo salvo com sucesso.

Outro exemplo de saída:

Erro: arquivo não encontrado.

Variáveis

Em programação, uma variável pode armazenar diferentes valores

Considere a expressão:

x = 10

y = 20

resultado = x + y

Glossário Front-end

HTML
Linguagem utilizada para estudar documentos Web
CSS
Linguagem utilizada para definir a apresentação visual
JavaScript
Linguagem utilizada para adicionar comportmaneto e interatividade
Front-end
Área relacionada ao processamento e funcionamento interno das aplicações.
Back-end
Área Relacionada à interface com a qual o usuário interage.

Relação entre o elemento utilizado e o significado do conteúdo.

Interface utilizada para permitir comunicação entre sistemas.

Endereço utilizado para localizar um recurso na Web.
